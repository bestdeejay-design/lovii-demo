# Утверждённые блоки и компоненты — галерея

Живая коллекция блоков и компонентов, прошедших приёмку владельца (начато 28.09.2026).
Открыть: `index.html` → http://localhost:8090/design/approved-components/ (и lovii.mobiap.com после пуша).

## Зачем
- Единое место «что уже утверждено и как это выглядит» — чтобы дорабатывать вместе и не спорить заново.
- У каждого компонента: имя для разговоров, живой вид, короткая спека, подсказка «где используется».

## Как добавить компонент
1. Скопируй секцию `<div class="comp">…</div>` и замени содержимое.
2. Живой вид собирай на токенах — значения в `:root` этого файла (источник: приложение и протоколы приёмок).
3. Тег: `принято <дата>`; строка «где используется» — обязательна.
4. Спека — 1–2 строки: размеры, токены, поведение.
