# LOVII Демо · Базовый стандарт компонентов ДС (v1)

Дата: 2026-09-19 · Ветка: design/staging-mirror
Источник истины: токены `assets/lovii-tokens.css` + зеркало стейджа
(`lovii-app@staging`). Правило: **один образец на компонент**, новые экраны
собираются только из этого набора.

## Карточки
| Тип | Класс | Где |
|---|---|---|
| Карточка-раскрытие | `.collapse` (`.collapse_open`) | профиль: Счёт/Статус/Избранные/Кабинеты |
| Софт-карточка | `.role-card` | кабинеты: разделы без раскрытия |
| Нав-карточка | `.profile__nav > section` | профиль: адреса/покупки/настройки-строки |
| Юридический блок | `.legal-card` | профиль: документы/поддержка |
| Строка-запись | `.msp-order-row`, `.msp-product-row` | кабинеты МСП |

Единый стандарт блока профиля и кабинетов: фон `--lv-card` (soft:
`--background-normal-surface`), **рамка `1px --lv-line`**, радиус
`--lv-r-lg` (16px), мягкая тень `--lv-shadow-soft`, внутренний паддинг 16px.
Исключение — стеклянные плашки (CTA-зоны) и полноширинные списки кабинетов.

## Кнопки и действия
- Основная CTA: `.acct__btn_brand` / `.pass__cta` — пилюля 44px,
  градиент `--lv-gradient-brand` или `--lv-pink`, текст `--lv-on-brand`.
- Вторичная: `.acct__btn` — пилюля с рамкой `--lv-line`.
- Чип выбора: `.app-chip` (+`.active` — акцент роли).
- Сегмент (3–4 выбора): `.seg` — один компонент на все случаи
  (тема, размер текста, анимации, способ получения).
- Переключатель: `.app-switch` / `.lv-switch` — 44×26, on = tiffany.
- Таб-бары: `.nav-btn` (витрина) и `.cabinet__bar-link` (кабинеты) —
  индикатор сверху, активная — розовая/цвет роли.

## Пилюли и статусы
- Статус точки/заказа: `.cabinets__tag_*`, `.role-tag`, `.role-status`.
- Бейджи: `.app-badge` (xs/s/m) + тона brand/gold/tiffany/tertiary.
- «Скоро»: `.app-badge_tertiary`; статистика героя: `.stat-pill`.

## Типографика (базовые кегли, без `--font-scale` — масштаб через zoom)
- h1 26/800 (≥640: 32) · заголовки секций 16/800 · строки 14/600 ·
  текст 13/400 · подписи 12/400 · капсы 11/800 (0.08em).

## Запрещено
- Эмодзи в интерфейсе (канон PRODUCT_QUALITY_BAR) — только в демо-данных
  вместо фотостока (`.sf-emoji`).
- Вторые образцы одного компонента: перед добавлением нового класса —
  проверь этот файл.
