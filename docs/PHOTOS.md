# Фото для витрины: сервис и правила

Как в витрине появляются фотографии товаров и заведений, откуда они берутся и как добавить новые.

## Сервис

**PicSUM:DEV** — https://www.picsum.dev · бесплатный, без регистрации и ключей.
Отдаёт картинки прямо по URL. Услуга заявлена как бесплатная для коммерческого использования.

### Что умеет

| Что нужно | Запрос | Примечание |
|---|---|---|
| Картинка размера W×H | `GET https://picsum.dev/{w}/{h}` | случайная |
| Квадрат | `GET https://picsum.dev/random/{size}` | напр. `/random/1024` |
| Один и тот же кадр по ключу | `GET /{w}/{h}?seed={любое}` | удобно для аватаров: `?seed=user-42` |
| Один и тот же кадр на размер | `GET /{w}/{h}?static` | стабильно для макета |
| Размытие / ч-б | `GET /{w}/{h}?blur=0..10`, `?grayscale=1` | можно вместе |
| Кадр из галереи по id | `GET /i/{id}/{w}/{h}` | детерминированно, id из галереи |
| **Генерация по описанию** | `POST /gallery/generate` | параметр `prompt` — наше описание |

Ограничения размеров: ширина и высота от 1 до 5000 px. Галерея — 1300+ AI-картинок по 13 категориям.

### Генерация по описанию — как это работает

Запрос требует сессионной cookie и CSRF-токена со страницы галереи:

```bash
# 1) берём cookie и токен
curl -s -c cookies.txt https://www.picsum.dev/gallery -o gallery.html
TOKEN=$(grep -o 'name="csrf-token" content="[^"]*"' gallery.html | cut -d'"' -f4)

# 2) просим картинку
curl -s -b cookies.txt -X POST https://www.picsum.dev/gallery/generate \
  -H 'Content-Type: application/json' -H 'Accept: application/json' \
  -H "X-CSRF-TOKEN: $TOKEN" \
  -d '{"category":"food","prompt":"latte in a paper cup, top view"}'
```

Ответ:

```json
{"success":true,"id":1313,"url":"https://www.picsum.dev/images/ai/food/food-….jpg",
 "detail":"https://www.picsum.dev/gallery/1313","category":"food",
 "prompt":"…","width":1024,"height":1024}
```

Категория — **своя у сервиса**, не наша: `nature, animals, food, architecture, technology,
business, travel, abstract, people, fashion, sports, space, art`. Если передать чужую —
приходит `422 Unprocessable Entity`. Поэтому в скрипте есть карта «категория демо → категория сервиса».

## Правила проекта

1. **Не хотлинкать.** Картинки скачиваются один раз и лежат в репозитории: `assets/photos/<slug>.jpg`.
   Витрина — PWA, она должна открываться и без внешней сети; чужой сервис однажды может измениться.
2. **Уменьшаем до 512 px** по длинной стороне (macOS `sips`). Исходники приходят 1024×1024 — для
   карточек это лишний вес, одна картинка занимает 20–70 КБ вместо 200–400 КБ.
3. **Записываем происхождение.** `assets/photos/photos.json` хранит по каждому файлу: id, промпт,
   категорию, ссылку-источник, дату получения и размер. Так видно, что это AI-генерация, и её можно воспроизвести.
4. **Эмодзи остаётся запасным вариантом.** Если фото для позиции нет, витрина рисует прежнюю
   эмодзи-плитку — ничего не ломается.

## Как пользоваться

```bash
cd ~/LOVII/sz062-2026-09-20/lovii-demo

python3 scripts/fetch-photos.py            # сгенерировать и скачать недостающие
python3 scripts/fetch-photos.py --list     # что уже есть и с какими промптами
python3 scripts/fetch-photos.py --only daily,sloyka
python3 scripts/fetch-photos.py --limit 10 # порциями, чтобы не долбить сервис
```

Скрипт сам берёт список заведений и товаров из `js/data.js`, строит промпт по категории
и имени, генерирует картинку, уменьшает её и дописывает манифест. Повторный запуск
не трогает то, что уже скачано.

### Как добавить фото новой позиции

1. Добавьте позицию в `js/data.js` (slug, name, category).
2. Запустите `python3 scripts/fetch-photos.py --only <slug>`.
3. Промпт получится из категории; если нужен особый — поправьте `CATEGORY_PROMPT` в скрипте.

### Как заменить неудачный кадр

Удалите файл и запись из `assets/photos/photos.json`, запустите скрипт заново —
сгенерируется другой вариант. Если хочется гарантированной повторяемости, используйте
`/i/{id}/{w}/{h}` с id из галереи (`https://www.picsum.dev/gallery/<id>`).

## Что где лежит

| Путь | Что |
|---|---|
| `assets/photos/*.jpg` | сами картинки, 512 px, по slug позиции |
| `assets/photos/photos.json` | манифест: промпт, id, источник, дата |
| `scripts/fetch-photos.py` | генерация и скачивание |
