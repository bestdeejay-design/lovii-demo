## 4. Зафиксированные паттерны (переиспользовать)

- **Раскрывающийся блок:** `collapseCard(key, title, sub, body)` в `club.js`; классы `.collapse-card / .cc-head / .collapse-body / .cc-inner`. Раскрытие **на месте**, без перерисовки вида; ширина — как у `.list-card`; внутри колонок — без боковых отступов.
- **Поверхности и цвет:** только токены — `--lv-card`, `--lv-surface`, `--lv-line`, `--lv-line-2`; тени — `--lv-shadow-soft` / `--lv-shadow-lift`; фокус — `--lv-ring-field`; разделители — `--lv-hairline`.
- **Карты:** скины `.skin-pay / .skin-pass / .skin-vip / .skin-biz`; карусель `.pay-carousel` + `.pay-slide`.
- **Списки:** `.list-card` + `.row-item / .ri-emoji / .ri-mid / .ri-right`.
- **Жёстко:** ничего не придумывать по цвету (сломается в тёмной теме), проверять обе темы.

## 5. Открытые задачи

1. **Плашка «скоро»** на карточке точки до комплаенса: точка видна в радиусе, продажи закрыты.
2. **Сотрудник — логика присоединения и статус в БД** (не описана): роли «Администратор» (товары + заказы) и «Сотрудник» (только заказы); привязка к точкам юрлица; приглашение по телефону; поля и статусы в базе.
3. **Роли клиента:** у одного клиента может быть несколько ролей → от набора зависят функции и ссылки на кабинеты. Сейчас: МСП / Представитель / Амбассадор — по промокоду, Владелец / Инвестор / Сотрудник — по назначению владельца.
4. **Адаптивная ширина app/:** сейчас капсула `max-width: 480px`; зафиксировать и поддержать более широкие экраны (ПК, фолд) — сетки, две колонки, без обрезки.
5. **Представитель** — убрать лишнее, привести к сути.
6. **Амбассадор** — то же: амбассадор привлекает и обучает представителей, представитель — привлекает МСП и обучает их.
7. **Услуги** — сценарий с временем и местом оказания.
8. **Сброс демо-состояния** одной кнопкой.

## 6. Правила работы (важно)

- Не менять существующие экраны без прямой просьбы владельца.
- Минимум полей: у МСП достаточно **ИНН + карточка торговой точки**.
- Не изобретать цвета и отступы — только классы и токены дизайн-системы.
- В профиле — не трогать раскладку без запроса.
- Язык интерфейса — русский; файлы/классы — латиница.
