# LOVII Витрина — демо · lovii.mobiap.com

**Живое демо: https://lovii.mobiap.com** (GitHub Pages, репозиторий `bestdeejay-design/lovii_demo`, домен привязан файлом `CNAME` — не удалять).

Клиентская витрина LOVII: торговые точки района выкладывают товары и услуги,
клиент находит точку и товар и видит, **где он есть в наличии** и сколько минут
идти пешком. Работает полностью на статике — сервер не нужен.

Плюс **роли из профиля** (требования REQUIREMENTS.md): торговая точка,
представитель, амбасадор + демо-доступ владельца и инвестора. Всё демо,
без авторизации — роли хранятся в `localStorage`.

## Роли (всё через профиль, без авторизации)

| Роль | Как попасть | Что внутри |
|---|---|---|
| **Клиент** | по умолчанию | витрина, поиск, корзина, заказы, избранное (♥ на товаре) |
| **Торговая точка** | Профиль → «Стать точкой» | заявка → авто-модерация ≈8 с → точка и её товары появляются на витрине района; выручка (день/неделя/месяц) с графиком, топ-5 товаров, управление товарами, карточка точки |
| **Представитель** | Профиль → «Стать представителем» | 5 подключённых точек (активна/подключается/offline), выручка сети, конверсия, топ точек, чаты с точками (авто-ответы, уведомления о заказах) |
| **Амбасадор** | Профиль → «Стать амбасадором» | дерево структуры (вы → представители → точки), выручка, рост, топ представителей, личные и групповой чаты |
| **Владелец** (демо) | Профиль → Демо-доступ | выручка платформы, регионы/точки с фильтром, экспорт CSV, финансы (комиссия, выплаты, OPEX, прибыль), дерево всех амбасадоров |
| **Инвестор** (демо) | Профиль → Демо-доступ | рост (пользователи, точки, GMV + прогноз), продажи по категориям, ROI / CAPEX / OPEX, окупаемость |

Переключение: Профиль → «Войти как …», выход в клиент — кнопкой «Клиент» в шапке дашборда.
Данные ролей детерминированы (PRNG с сидом) — графики не «мигают» между рендерами.

## Деплой за 3 минуты (через сайт GitHub)

> ⚠️ **Домен и кэш**: файл `CNAME` в корне держит привязку lovii.mobiap.com — при любых
> заливках оставляйте его на месте. После правок css/js поднимайте версию `?v=N` в index.html
> (например, `css/lovii.css?v=13` → `?v=14`) — иначе посетители получат старые файлы из кэша.

1. Создайте репозиторий на github.com (например, `lovii`).
2. **Add file → Upload files** и перетащите **всё содержимое** этой папки
   (index.html, папки `css/`, `js/` и `assets/`, manifest.webmanifest, README, .nojekyll). Commit.
   - Если браузер не даёт загрузить `.nojekyll` (файл с точкой): **Add file →
     Create new file**, в имени введите `.nojekyll`, оставьте пустым и закоммитьте.
3. Откройте **Settings → Pages**, в блоке «Build and deployment»:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка: **/ (root)** → Save.
4. Через 1–2 минуты витрина будет доступна по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Почему всё работает без настроек

- **Hash-роутинг** (`#/product/cr-almond`, `#/dash/chats`) — обновление страницы
  и прямые ссылки не дают 404.
- **Относительные пути** — сайт работает и в корне (`user.github.io`), и в
  подкаталоге (`user.github.io/lovii/`).
- **Нет сборки** — чистые HTML/CSS/JS, ничего не нужно компилировать.
- Корзина, заказы, избранное, роли и чаты хранятся в `localStorage` браузера.

## Как менять данные (js/data.js)

- **Районы** — `districts`: имя, метро, координаты позиции клиента.
- **Точки** — `stores`: координаты `lat/lng` (по ним автоматически считаются
  минуты пешком), часы работы, описание, теги.
- **Товары** — `products`: базовая цена и наличие `avail: [точка, остаток, ±цена]`.
- **Акции** — `promos`.
- **Роли и дашборды** — `LOVII_DASH`: подключённые точки представителя
  (`repPoints`), структура амбасадора (`ambReps`, `ambassadors`), финансы
  платформы (`finance`), динамика для инвестора (`investor`), товары новой
  точки (`storeGoodsSeed`), сиды чатов (`chatSeeds`).
